插件管理 1.5.0 —— 安装到 iPhone
====================================

本文件夹里是一个完整的可安装包 + 安装工具 + 源码。
.deb 是 iOS 的安装包格式，Windows 上无法直接安装，它必须装到手机上。


------------------------------------------------
文件说明
------------------------------------------------

插件管理-1.5.0-arm64.deb    安装包本体
repo\                        Sileo 本地软件源（含索引）
一键安装到手机.ps1            双击即用，自动找设备并安装
deploy.ps1                   同上的命令行版，可指定 IP / 端口
find-device.ps1              只扫描局域网找 iPhone
serve-sileo.ps1              起本地源，让 Sileo 直接装
源码\                        完整工程，可自行重新编译


------------------------------------------------
路线 A：一键安装（手机已装 OpenSSH，最快）
------------------------------------------------

1. 手机与电脑连同一个 WiFi
2. 手机 设置 -> WiFi -> 点当前网络 -> 记下「IP 地址」
3. 在本文件夹按住 Shift + 右键 -> 「在此处打开 PowerShell 窗口」，输入：

       powershell -ExecutionPolicy Bypass -File .\一键安装到手机.ps1

4. 按提示输入 IP 和密码（Dopamine 默认 alpine，没改过直接回车）
5. 脚本自动完成：上传 -> dpkg 安装 -> 修权限 -> 刷新图标 -> 注销

也可直接指定参数：

       powershell -ExecutionPolicy Bypass -File .\deploy.ps1 -Device 192.168.1.50 -Password alpine


------------------------------------------------
路线 B：Sileo 本地源（不用 SSH）
------------------------------------------------

1. 手机与电脑连同一个 WiFi
2. 在本文件夹运行（保持窗口开着）：

       powershell -ExecutionPolicy Bypass -File .\serve-sileo.ps1

   它会打印一行「源地址」，例如 http://192.168.1.10:8899/
3. 手机打开 Sileo -> 软件源 -> 右上角 + -> 粘贴该地址 -> 添加
4. 源里出现「插件管理」-> 安装
5. 装完关掉电脑上的窗口即可

Windows 防火墙如果弹窗，选「允许访问」。


------------------------------------------------
路线 C：把 deb 传到手机手动装
------------------------------------------------

1. 用微信 / QQ / AirDrop / iCloud 把 插件管理-1.5.0-arm64.deb 传到手机
2. 手机「文件」App 里长按它 -> 分享 -> 用 Sileo 打开 -> 安装
3. 装完注销一次


------------------------------------------------
装完之后
------------------------------------------------

桌面出现「插件管理」App，图标是紫蓝渐变 + 白色开关。

界面结构：
  · 顶部搜索框：按插件名或用途过滤
  · 「未开启」分组在最上面，「已开启」在下面
  · 每行：色块图标 + 插件名 + 一行用途 + 开关
  · 点行右侧的小箭头 ▾ 展开详情（Bundle ID、进程、文件、包名、大小、时间）
  · 点整行弹出操作面板（分享 / 提取 dylib / 包信息 / 备份 / 改名 / 启停）
  · 右上角 ... 菜单：重启 SpringBoard（注销）、重启用户空间、
                     全部启用、全部停用、文件管理、刷新


------------------------------------------------
使改动生效
------------------------------------------------

开关拨动后只是写盘，还没生效。必须点右上角 ... -> 「重启 SpringBoard（注销）」，
黑屏 3-8 秒回到桌面后，被停用的插件才真正停止加载。

注销后仍不生效（少见），再用「重启用户空间」（5-20 秒）。


------------------------------------------------
故障排查
------------------------------------------------

「特权助手不可用」
    SSH 上执行：chmod 4755 /var/jb/usr/libexec/pluginmanager/pmhelper

「未检测到插件注入目录」
    没装 ElleKit。Sileo 里装上后重开 App。

开关拨了但插件还在跑
    没注销，或需要重启用户空间。

桌面没图标
    SSH 执行：uicache -a && sbreload

文件管理里按钮是灰的 / 提示缺少 libarchive
    设备缺 libarchive.2.dylib，文件管理不可用；插件开关不受影响。

卸载
    Sileo 里卸载「插件管理」。会自动把所有被禁用的插件恢复原名，
    不会留下「插件卡在禁用状态」的坑。
