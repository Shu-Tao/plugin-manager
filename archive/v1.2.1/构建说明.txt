插件管理 —— 源码构建说明
============================

本目录（源码\）含完整工程，可自行重新编译出 .deb。


------------------------------------------------
工具链
------------------------------------------------

构建不依赖 WSL，也不需要管理员权限。需要：

  zig               做 Apple 目标编译（zig cc）
  llvm-mingw 的 ld.lld   做 Mach-O 链接（-flavor darwin）
  iPhoneOS16.5.sdk  头文件与 tbd 存根
  zsign             ad-hoc 签名 + entitlements

首次运行 scripts\bootstrap-toolchain.ps1 会自动下载到
E:\DataBackup\toolchain（约 1.3 GB）。

若该目录已存在，构建脚本会直接复用，不会重复下载。


------------------------------------------------
编译
------------------------------------------------

  cd 源码
  powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Clean

产物输出到 build\dist\com.yg.pluginmanager_<版本>_iphoneos-arm64.deb


------------------------------------------------
构建脚本做了什么
------------------------------------------------

1. 编译 App（13 个 .m）与特权助手（3 个 .m + 3 个 .c）
2. ld.lld 链接，平台版本锁 ios 15.0
3. zsign ad-hoc 签名，分别注入 entitlements-app / entitlements-helper
4. 组装 layout\ 目录树（App bundle + pmhelper）
5. 纯 Python 的 mkdeb.py 打 ar + control.tar.xz + data.tar.xz
6. 跑三组单测（35 + 22 + 22 项）
7. verify-deb.py 自检 27 项（结构、路径、权限、Mach-O、签名）

任一步失败都会中断并打印原因。


------------------------------------------------
单独跑测试
------------------------------------------------

  powershell -ExecutionPolicy Bypass -File scripts\test-core.ps1

或直接跑各测试可执行文件（构建后在 build\ 下）。


------------------------------------------------
工程结构
------------------------------------------------

src\app\          App 端（ObjC + ARC + UIKit）
  PMListViewController    列表 / 搜索 / 分组 / 菜单
  PMSwitchCell            插件行（色块 + 标题 + 用途 + 小箭头 + 开关）
  PMChevron               自绘 V 形箭头（角度与边长可调）
  PMActionSheet           底部操作面板（自绘 presentation）
  PMFileBrowserViewController  文件管理页
  PMStore / PMPluginItem  数据层
  PMHelperClient          调助手，JSON 解析与错误翻译
  PMHostNames             Bundle ID -> 中文用途映射
  PMTheme / PMToast       配色与提示

src\helper\       特权助手（setuid root）
  pmhelper.m              命令分发
  PMFsOps.c               插件开关：规划 / 执行 / 回滚 / 扫描
  PMProcOps.c             进程表操作：注销走内核发信号，不依赖 sbreload
  PMArchiveOps.c          deb/tar/zip 操作，libarchive 运行时 dlopen
  PMPaths.m / PMScanner.m 路径探测与条目组装

tests\            宿主机单测（Windows / Linux 均可跑）
resources\        Info.plist / entitlements / control / 图标
scripts\          bootstrap / build / deploy / mkdeb / verify-deb / test-*


------------------------------------------------
修改后重新出包
------------------------------------------------

改版本号：编辑 VERSION 文件（构建时注入 control）

改最低系统：build.ps1 -MinIOS 14.0

改箭头大小/角度：src\app\PMSwitchCell.m 顶部
    kChevronGlyphWidth   宽（越大开口角度越大）
    kChevronGlyphHeight  高（越小两边越短）
    kChevronStroke       线宽

改中文用途映射：src\app\PMHostNames.m 里的映射表


------------------------------------------------
已知边界
------------------------------------------------

· dpkg 重装某插件会把文件恢复原名，该插件自动变回启用态
· 插件的 .dylib 与 .plist 必须同名（Theos 默认约定）
· 文件管理依赖设备上的 libarchive.2.dylib，缺失时该功能不可用，
  插件开关不受影响
